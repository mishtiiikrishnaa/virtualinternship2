Week 3 delivers a complete browser-based interactive learning module that teaches programming fundamentals to absolute beginners with no prior technical background. The module covers variables and data types, operators and expressions, conditional statements, loops, functions, and basic algorithmic thinking with debugging, following the concepts introduced in the Week 2 curriculum. Examples are written in Python and execute accurately in the browser through Pyodide, avoiding any misrepresentation of simulated results.

The application includes an accessible explanation and real-world analogy for each concept, annotated code examples, interactive visualisations, predict-the-output exercises, hands-on experimentation, instant explanatory feedback, common beginner mistakes, progressive exercises, and practical activities. Interactive components include a variable assignment visualiser, a conditional decision simulator, a step-by-step loop visualiser, a function input-output simulator, Parsons problems, debugging challenges, quizzes, and a guided final mini-project combining multiple concepts.

The interface is responsive, uses consistent typography and spacing, supports keyboard navigation, tracks progress with localStorage, and provides reset and retry functionality. A professionally formatted Word report documents the complete design and implementation across all required sections, including instructional diagrams, screenshots, session plans, facilitator guidance, assessment strategies, rubrics, testing evidence, accessibility considerations, and references. Supporting deliverables include diagrams, screenshots, assessment materials, answer keys, test documentation, and a README with installation, usage, features, and GitHub Pages deployment instructions. The repository remains organised without overwriting previous submissions.

Evaluation materials include diagnostic, formative, and summative assessments, a learner self-assessment checklist, peer feedback forms, facilitator observation checklists, and a one-hundred-mark analytical rubric with differentiated performance levels. Testing verifies example correctness, quiz answers, interactive functionality, progress persistence, responsive layouts, keyboard navigation, reset behaviour, invalid input handling, and absence of console errors.
