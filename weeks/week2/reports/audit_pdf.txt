Executive summary
This document develops the week 2 content for a programming fundamentals module for non-programmers. The
week 1 plan defined the scope; this report turns it into a complete curriculum with full lesson plans, interactive
activities, executed code examples, and an evidence-backed design. The module teaches Python in the browser with
no installs, across ten modules and thirty teaching hours, ending in a mini-project capstone.
Every technical concept is explained in plain English first, then tied to a real-life analogy that states where it breaks
down. Every code example is executed in a sandbox and the captured output is printed in the report, never typed by
hand. Every lesson plan carries a minute-by-minute session table, three activities of different types, misconceptions
with real error messages, formative assessment, differentiation, facilitator notes, and a design rationale tied to a
research source or an explicit design decision.
The final deliverable is a Word document that presents the complete curriculum, with lesson plans, topics, learning
activities, annotations, examples, and an interactive activity set. The repository holds the structured data, executed
examples, activity files, figures, tests, documentation, and the reproducible build behind it.

1 About this curriculum
This internship offer was received on 2 November 2026 and the internship runs from 2 November 2026 to 30
November 2026. This week 2 report was prepared on 6 November 2026. It develops the content and curriculum
building task: the aim is to introduce the fundamentals of programming to non-programmers with practical
examples that are easy to grasp.
The learners are adults or students who have never written a line of code. Their prior knowledge is everyday
computer use only. The curriculum assumes no programming background, no installs, and a browser. It does not
assume any maths beyond counting.
By the end of the module, a learner will be able to: describe a task as steps, store information in variables, ask and
show through input and output, choose with conditionals, repeat with loops, bundle steps into functions, organise
values into lists and dictionaries, read and write files, read a traceback, and combine the taught concepts into one
working small program they can explain in plain words.

module m2 of 10 - variables and data types. duration 180 minutes. prerequisites: m1.
objectives: m2-o1, m2-o2.

plain english and the real-life analogy
a variable is a name for a value the program can read and change, like a labelled box.
real-life analogy: a labelled box where you can put a number or a word, and later take the label off and use a
different value.
where this analogy breaks down: the box is not a box; reassigning changes what the name points to, not the box.

Module 4: Conditionals (If / Else)
module m4 of 10 - conditionals (if / else). duration 180 minutes. prerequisites: m3.
objectives: m4-o1.

plain english and the real-life analogy
a program can choose between two or more paths based on a condition.
real-life analogy: a traffic roundabout: if the light is green, go; if red, stop; otherwise follow the sign.
where this analogy breaks down: a roundabout has many roads; an if/else has a binary choice and a condition you
must write precisely.

worked example: a complete runnable program


age = 12
if age >= 13:
     print("you can watch the scary movie")
else:
     print("you must watch the gentle cartoon")
