## public beginner course structures
- [1] cs50x — harvard introduction to computer science. https://cs50.harvard.edu/x/ — topics include abstraction, algorithms, conditionals, loops, functions, arrays, strings. I used the topic list to sanity-check my module order, not to copy content.
- [2] py4e (python for everybody) — https://www.py4e.com/ and https://do1.dr-chuck.com/pythonlearn/EN_us/pythonlearn.pdf — free book and lectures, no prerequisites, data structures and web data in later chapters. I used its tiny-steps progression as a reference for session length.
- [3] automate the boring stuff with python — https://automatetheboringstuff.com/2e/ — chapter order: basics, flow control, functions, lists, dictionaries, file handling, regex, web scraping. I used its project-first framing for the capstone.
- [4] code.org computer science fundamentals — https://code.org/en-US/curriculum/computer-science-fundamentals — block-based for younger ages, unplugged activities first. I used the unplugged-first idea, not the age level.
- [5] raspberry pi foundation, supporting learners with parsons problems — https://www.raspberrypi.org/blog/supporting-learners-with-programming-tasks-through-ai-generated-parsons-problems/ (2024). describes parsons problems as reordering scrambled lines without writing from scratch.
- [6] teach computing, parsons problems quick read — https://static.teachcomputing.org/pedagogy/QR13-Parsons-problems.pdf

## teaching technique sources
- [7] mit tll, worked examples — https://tll.mit.edu/teaching-resources/how-people-learn/worked-examples/ — novices benefit from watching a fully worked example with the thinking made visible before attempting similar tasks.
- [8] parsons problems in computing education — kapor foundation strategy guide — https://kaporfoundation.org/strategies_guide/parsons-problem/ — explains the scrambled-lines format and typical use in intro classes.
- [9] pair programming meta-analysis and reviews — lui & yap (2006) novice-novice vs expert-novice; denner et al. (2014). preprints and abstracts found via search. I use only the general claim that pairing helps confidence and accuracy for novices, which is consistent across the sources I checked. [verify before citing: exact effect sizes]
- [10] worked examples and cognitive load review — https://dl.acm.org/doi/full/10.1145/3732791 and https://www.edresearch.edu.au/summaries-explainers/explainers/managing-cognitive-load-optimises-learning — worked examples reduce overload by showing steps before asking learners to produce them.

## language choice
- [11] scratch vs python comparisons — idtech blog and ciyclub. scratch suits younger beginners; python suits middle-school and older learners who are ready for text code. https://www.idtech.com/blog/scratch-vs-python
- [12] python readability — the python coding book on pep 8 and readability. https://thepythoncodingbook.com/2021/10/11/python-readability-the-pep-8-style-guide-and-learning-latin/
